# Кейс 1. Процесс отбора кандидата

Кейс показывает моделирование бизнес-процесса отбора кандидата: от отклика до приглашения на стажировку и фиксирует основные точки принятия решений.

## Что сделано

- описан процесс отбора кандидата;
- вынесен подпроцесс стажировочного задания;
- вынесен подпроцесс регистрации кандидата в системе;
- определены участники процесса;
- описаны основные и альтернативные сценарии;
- зафиксированы бизнес-правила и открытые вопросы.

## Участники

- Кандидат
- CRM / система
- Куратор / HR
- Руководитель
- Коллаба
