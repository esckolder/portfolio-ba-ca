# Кейс 1. Процесс отбора кандидата

Кейс показывает моделирование бизнес-процесса отбора кандидата: от отклика до приглашения на стажировку или отказа.

## Что сделано

- описан L1-процесс отбора кандидата;
- вынесен L2-подпроцесс стажировочного задания;
- определены участники процесса;
- описаны основные и альтернативные сценарии;
- зафиксированы бизнес-правила и открытые вопросы.

## Участники

- Кандидат
- CRM / система
- Куратор / HR
- Руководитель
- Коллаба
