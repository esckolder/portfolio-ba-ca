# Бизнес-правила процесса отбора кандидата

BR-CP-001. Кандидат не переходит к следующему этапу без завершения текущего действия.

BR-CP-002. Отказ после первичного отбора завершает процесс.

BR-CP-003. Стажировочное задание считается завершённым только после прохождения всех этапов и заполнения финальной анкеты.

BR-CP-004. Финальное взаимодействие с куратором начинается только после успешной финальной анкеты.

BR-CP-005. При несогласии кандидата на условия процесс завершается отказом кандидата.

BR-CP-006. При несогласовании руководителем процесс завершается отказом по решению руководителя.

BR-CP-007. При согласовании руководителем кандидат приглашается на стажировку.

BR-CP-008. Результаты ключевых этапов должны фиксироваться системой.

BR-CP-009. Кандидат должен получать понятный финальный результат процесса: приглашение или отказ.

BR-CP-010. Подпроцесс стажировочного задания должен быть завершён до перехода к финальной анкете.
