Репозиторий содержит учебные аналитические кейсы, подготовленные для демонстрации навыков бизнес- и системного анализа.

## Цель портфолио

Показать умение раскладывать бизнес-идею на структурированные аналитические артефакты:

- бизнес- и функциональные требования;
- BPMN-схемы;
- пользовательские сценарии;
- критерии приемки;
- ERD и модель данных;
- SQL-скрипты;
- статусные модели;
- открытые вопросы.

## Кейсы

### Кейс 1. Модель бизнес процесса

Кейс демонстрирует описание сквозного бизнес-процесса с участниками, точками принятия решений, альтернативными ветками и бизнес-правилами.

Артефакты:
- описание процесса;
- схема процесса;
- бизнес-правила;
- открытые вопросы.

### Кейс 2. Комбо-заказ

Учебный аналитический кейс по проектированию сценария объединённого заказа еды и такси.

Артефакты:
- бизнес-требования;
- функциональные требования;
- пользовательские сценарии;
- критерии приемки;
- BPMN;
- ERD;
- SQL;
- статусная модель.
