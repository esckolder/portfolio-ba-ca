# Acceptance Criteria

## Сценарий 1. Combo-предложение успешно создано

Given пользователь создал заказ еды  
And DeliveryOrder находится в подходящем статусе  
And такси доступно  
When Combo-система проверяет возможность combo-предложения  
Then создаётся ComboOffer  
And пользователь может принять или отклонить предложение

## Сценарий 2. Пользователь отклоняет предложение

Given ComboOffer отображается пользователю  
When пользователь отклоняет предложение  
Then ComboOffer получает статус declined  
And TaxiOrder не создаётся  
And DeliveryOrder остаётся без изменений

## Сценарий 3. Пользователь принимает предложение

Given ComboOffer отображается пользователю  
And срок действия ComboOffer не истёк  
When пользователь принимает предложение  
Then система передаёт команду на создание TaxiOrder  
And после создания TaxiOrder создаётся ComboOrder  
And DeliveryOrder и TaxiOrder связываются между собой

## Сценарий 4. Такси недоступно

Given DeliveryOrder создан  
And такси недоступно  
When Combo-система проверяет доступность такси  
Then ComboOffer не создаётся  
And DeliveryOrder остаётся без изменений  
And причина невозможности создать предложение фиксируется системой

## Сценарий 5. Истёк срок действия предложения

Given ComboOffer создан  
And expires_at меньше текущего времени  
When пользователь пытается принять предложение  
Then TaxiOrder не создаётся  
And пользователь получает сообщение о недействительном предложении  
And DeliveryOrder остаётся без изменений

## Сценарий 6. Ошибка создания TaxiOrder

Given пользователь принял актуальный ComboOffer  
When сервис такси не создаёт TaxiOrder  
Then Combo-сценарий завершается с ошибкой  
And DeliveryOrder остаётся без изменений  
And пользователь получает сообщение об ошибке
